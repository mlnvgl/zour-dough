## Development

1. Zig build
2. Flash
    - install picotool via ``` brew install picotool ``` which is neccessary for flashing process
    - run ``` zig run tools/flash.zig ```

3. Start serial loggers
    - open new terminal
    - run ``` zig run tools/serial-logger.zig ```
