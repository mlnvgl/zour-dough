  <name>Task 2: Create Dashboard JSON Model</name>
  <files>backend/grafana/dashboards/main.json</files>
  <action>
    Create a valid Grafana Dashboard JSON file `backend/grafana/dashboards/main.json` with:
    - Title: "Temperature Monitor"
    - Variable: `bucket` (constant, value: "sensors") to allow portability.
    - Panel 1 (Stat): "Current Temperature". Query: `from(bucket: "${bucket}") |> range(start: -5m) |> filter(fn: (r) => r["_measurement"] == "temperature") |> last()`.
    - Panel 2 (TimeSeries): "Temperature History". Query: `from(bucket: "${bucket}") |> range(start: v.timeRangeStart, stop: v.timeRangeStop) |> filter(fn: (r) => r["_measurement"] == "temperature")`.
    - Panel 3 (StateTimeline): "Heater Status". Query: `from(bucket: "${bucket}") |> range(start: v.timeRangeStart, stop: v.timeRangeStop) |> filter(fn: (r) => r["_measurement"] == "heater")`.
    
    Ensure the JSON structure is valid (panels array, title, timezone: browser).
  </action>
  <verify>
    cat backend/grafana/dashboards/main.json | grep "Temperature Monitor"
  </verify>
  <done>
    Valid JSON file exists with 3 specified panels.
  </done>
