<task type="auto">
  <name>Task 1: Configure Mosquitto and Environment Secrets</name>
  <files>backend/mosquitto/config/mosquitto.conf, backend/stack.env</files>
  <action>
    1. Create `backend/stack.env` to store InfluxDB initialization secrets:
       - DOCKER_INFLUXDB_INIT_MODE=setup
       - DOCKER_INFLUXDB_INIT_USERNAME=admin
       - DOCKER_INFLUXDB_INIT_PASSWORD=password123
       - DOCKER_INFLUXDB_INIT_ORG=zour_dough
       - DOCKER_INFLUXDB_INIT_BUCKET=sensors
       - DOCKER_INFLUXDB_INIT_ADMIN_TOKEN=my-super-secret-token-change-me
    2. Create `backend/mosquitto/config/mosquitto.conf` to allow external connections (essential for v2.0+):
       - `listener 1883`
       - `allow_anonymous true`
       - `persistence true`
       - `persistence_location /mosquitto/data/`
  </action>
  <verify>
    ls -l backend/stack.env backend/mosquitto/config/mosquitto.conf
  </verify>
  <done>
    Environment variables defined and Mosquitto config allows anonymous access on port 1883.
  </done>
</task>

<task type="auto">
  <name>Task 2: Configure Telegraf Bridge</name>
  <files>backend/telegraf/telegraf.conf</files>
  <action>
    Create `backend/telegraf/telegraf.conf` to bridge MQTT to InfluxDB.
    - Input: `[[inputs.mqtt_consumer]]` listening on `tcp://mosquitto:1883`, topic `sensors/#`, `data_format = "json"`.
    - Output: `[[outputs.influxdb_v2]]` sending to `http://influxdb:8086`.
    - Use token variable: `token = "$DOCKER_INFLUXDB_INIT_ADMIN_TOKEN"` (Telegraf expands env vars).
    - Set `organization = "zour_dough"` and `bucket = "sensors"`.
  </action>
  <verify>
    grep "inputs.mqtt_consumer" backend/telegraf/telegraf.conf && grep "outputs.influxdb_v2" backend/telegraf/telegraf.conf
  </verify>
  <done>
    Telegraf configuration exists with correct input/output plugins and variable references.
  </done>
</task>

<task type="auto">
  <name>Task 3: Orchestrate with Docker Compose</name>
  <files>backend/docker-compose.yml</files>
  <action>
    Create `backend/docker-compose.yml` defining three services:
    1. `mosquitto`: image `eclipse-mosquitto:2.0`, ports `1883:1883`, volumes for config and data.
    2. `influxdb`: image `influxdb:2.7`, ports `8086:8086`, env_file `stack.env`, volumes for data.
    3. `telegraf`: image `telegraf:1.29`, env_file `stack.env`, volumes for config, depends_on mosquitto & influxdb.
    
    Ensure all services share a bridge network (default in compose).
  </action>
  <verify>
    docker-compose -f backend/docker-compose.yml config
  </verify>
  <done>
    Valid docker-compose file created that mounts all configs and passes environment variables.
  </done>
</task>
